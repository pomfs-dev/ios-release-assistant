About This Tool

이 도구를 만드는 이유

개발 언어를 몰라도, 바이브 코딩으로 만든 iOS 앱을 App Store 제출 준비 상태까지 데려가기 위한 설정 도우미입니다.

배경

앱을 만드는 일은 쉬워졌지만, 앱을 App Store에 올리기 전 설정은 여전히 어렵습니다. Xcode에는 낯선 단어가 많고, 어떤 값이 실제 앱의 어디에 보이는지 알기 힘듭니다. 이 도구는 어려운 설정 이름을 먼저 보여주지 않고, 쉬운 질문에 답하면 출시 준비에 필요한 파일을 정리해주는 것을 목표로 합니다.

누구를 위한 것인가요?

  • Xcode를 처음 열어본 앱 제작자
  • 개발 언어를 모르지만 바이브 코딩으로 앱을 만든 사람
  • App Store 제출 전에 무엇을 준비해야 하는지 알고 싶은 사람
  • 복잡한 설정 파일을 직접 만지기 무서운 사용자

무엇을 도와주나요?

  • 앱 이름, 고유 주소, 버전 설정
  • 카메라/위치/마이크 권한 문구 준비
  • Apple 로그인, 푸시 알림 같은 기능 설정
  • 개인정보와 심사 준비 항목 점검
  • App Store 상품 정보, 스크린샷, 가격, 출시 국가 준비
  • 마지막에 Xcode에서 열 수 있는 프로젝트 파일 생성

어떻게 동작하나요?

  • 사용자는 브라우저 화면에서 질문에 답합니다.
  • 앱 폴더 안의 설정 파일을 안전하게 수정합니다.
  • XcodeGen이라는 도구로 Xcode 프로젝트 파일을 만듭니다.
  • 무엇이 바뀌었는지 쉬운 말로 보여줍니다.
  • 개발자용 자세한 정보는 접어서 보여줍니다.

GitHub가 필요한가요?

필요하지 않습니다. 이 도구는 사용자의 Mac 안에 있는 앱 폴더를 기준으로 동작해야 합니다. GitHub 계정이나 원격 저장소가 없어도 사용할 수 있어야 합니다. Git을 모르는 사용자를 위해서는 자동 백업 폴더를 만든 뒤 진행하는 모드가 필요합니다.
